# Salut, moi c'est Louis-Gériel 👋

**Développeur web** (Next.js + TypeScript), **artiste 3D** avec Blender et **professeur d'anglais** à Libreville, au Gabon.

Je construis des produits web concrets et j'aime les relier au monde réel : une photo, un objet, une idée qui devient une application.

## 🚀 En ce moment

**[snapme](https://snap-me-omega.vercel.app)** : une application qui apprend l'anglais à partir des objets qu'on photographie. Gemma 4 reconnaît l'objet et écrit la leçon, une voix générée dans le navigateur le prononce. Réalisée pour le Hacktoberfest Hack Day Libreville 2026.

- [Essayer la démo](https://snap-me-omega.vercel.app)
- [Voir le code](https://github.com/Nelge-3D/snap-me)
- [Lire l'article sur DEV](https://dev.to/nelge3d/snap-me-learn-english-from-the-objects-around-you-with-gemma-4-and-a-voice-that-runs-in-your-4ie6)
